# 取得応答のフィクスチャ

匿名の公開空き状況から、Cookie・認証情報を含めず保存したJSON。テスト実行時は公式へ通信しない。

- `grass-11.json`、`hard.json`：2026-10-10取得、2026-10-10開始の7日間。既存の人工芝・ハード解析テスト用。
- `grass-past.json`：2026-10-10 19:22頃（日本時間）取得、東大和南公園・人工芝、2026-10-05開始の7日間。DBのワーカー制御を通す単発取得で確認。必要な日付・時間・状態・面数だけを保存。

`grass-past.json`は28セル中、過去日の20セルが`status=700 / alt=受付期間外 / rsvNum=0`、10日・11日の8セルが`status=210 / alt=予約あり / rsvNum=0`。700は空き枠に出力しない。休止・営業時間外等の他の状態は未確認で、未知の状態は引き続き取得失敗とする。

公式の[操作マニュアル（予約・利用当日、3ページ）](https://kouen.sports.metro.tokyo.lg.jp/webcontents/reservation.pdf)でも、時間外・受付期間外は空きとは別表示である。予約受付期間と検索可能期間の上限は同一とは限らず、受付期間の説明だけで検索日の上限を推定しない。
