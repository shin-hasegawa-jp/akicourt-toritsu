# 開発基盤のレビュー記録

2026年10月10日。対象は01-3（開発設定）、01-4（VueとFastifyの最小接続）、追加依頼の01-5（Docker）。開発者対応のVue・Fastify初期化はPR #1・#2として反映済み。最新developから本ブランチを作成した。

## レビュー単位01-3：開発設定

- Node 24.18.0を.nvmrcで固定し、web/apiのenginesを24系に揃える。
- APIの型チェックを明示し、PORTとAPI_HOSTで起動先を変更できるようにする。
- READMEへホスト起動、検証、Dockerの手順を記載し、.envと生成物を除外する。
- パッケージの追加・更新・削除はない。ロックファイルの差分はenginesのメタデータのみ。

完了条件：Web/APIを指定ポートで起動・確認でき、環境と手順が再現可能。

## レビュー単位01-4：最小接続

- 副作用のないGET /healthと、Vueの接続確認画面を追加。
- 開発プロキシで/api/healthをFastifyの/healthへ転送。
- 通信中も入力可能、5秒のタイムアウト、失敗表示、再試行に対応。
- Vitestの設定をViteの環境別設定へ合わせる。

完了条件：実Fastifyへのブラウザ接続、停止時の失敗表示、復旧後の成功を確認できる。

## レビュー単位01-5：Docker

- manga-kuraと同様、プロジェクト名とホスト公開ポートを環境変数で指定。
- 既定値はakicourt-toritsu、Web 17590、API 17591。公開先は127.0.0.1。
- コンテナ間接続はapi:3000。ホストポート変更時もプロキシ先は変わらない。
- 非rootユーザーで起動。ソースを共有し、node_modulesとAPIのdistをプロジェクト別ボリュームへ分離。
- 起動時にnpm ciで既存ロックから依存を復元する。新規依存導入ではない。
- ボリューム上のdistを消せるよう、APIのcleanはdistの中身のみ削除する。

完了条件：別ポート・別プロジェクト名で起動し、既存プロジェクトと併用できる。
