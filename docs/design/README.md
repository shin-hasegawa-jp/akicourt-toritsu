# 検索画面の確認画像

`desktop-sample.png`、`mobile-sample.png`、`mobile-picker.png`は、確認用サンプルAPIを使ってブラウザで撮影した画像です。実際の空き状況や予約可否を示していません。

`comparison-*.png`は、チャットで選択したデザインと実装の比較です。`comparison-mobile-before.png`は調整途中の記録です。確認条件・指摘・修正内容は[デザイン確認記録](../../design-qa.md)を参照してください。

実APIでの検索確認は別途行い、保存済みデータの表示と開始時刻の絞り込みを確認しています。公式への新規取得・全対象のE2E成功とは区別します。
